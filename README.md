# My First Project

My first project on GitHub — where I started learning to code.

## What is this?

This repository holds my very first program: a simple "Hello, World!" program written in C++ (`hello.cpp`). I created this repo when I was starting out with programming, and I am keeping it here as the starting point of my coding journey.

## The program

`hello.cpp` prints `Hello, World!` to the screen. It is the classic first program every programmer writes.

## How to run it

You need a C++ compiler (for example, g++):

```bash
g++ hello.cpp -o hello
./hello
```

You should see:

```
Hello, World!
```
